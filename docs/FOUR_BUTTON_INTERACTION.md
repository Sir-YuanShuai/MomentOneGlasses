# 四键交互与 STT 状态机

> 验证日期：2026-07-29  
> 验证环境：Rokid Craft `Interactive InkView` 与 `@yodaos-pkg/ink 0.14.0`

MomentOne 将主要交互收敛为官方交互调试面板中的四种操作。页面上的触摸按钮保留为辅助入口，但业务状态迁移必须可以只靠四键完成。

## 1. 官方调试面板映射

| Craft 操作 | 页面事件码 | MomentOne 语义 |
|---|---|---|
| 返回 | `Backspace` | 取消当前监听、返回上一页或退出当前层级 |
| 点击 | `Enter` | 激活当前焦点；监听中用于完成输入 |
| 上滑 | `ArrowUp` | 移动到上一个可操作项 |
| 下滑 | `ArrowDown` | 移动到下一个可操作项 |

电脑键盘的 `Escape` 在 Craft 中也会触发“返回”。MomentOne 在页面侧同时兼容 `Escape`，但不把 `GlobalHook` 作为核心交互路径。

统一映射位于 `services/controls.js`。页面必须在 `onKeyUp(event)` 中调用 `event.preventDefault()` 后提供明确的替代行为，避免宿主继续执行默认返回、滚动或激活动作。

本地 Flight Recorder 调试页与 Craft 的入口方式不同：它不绑定电脑键盘，只保留“返回、点击、上滑、下滑”四个 UI 按钮，由按钮主动向 InkView 派发上述事件码。这样调试表单输入不会误操作 AIUI 页面。

## 2. 页面交互规则

### 记录页

- 上滑/下滑：在“记录这一刻、时间线、问记忆”之间移动焦点。
- 点击：激活焦点；记录中再次点击表示完成记录。
- 返回：记录中取消本次记录；AI 正在整理时拦截返回并提示等待；空闲时保留宿主默认退出行为。
- 语音唤醒：空闲、已保存或错误状态下直接开始记录。

### 时间线

- 上滑/下滑：依次选择 Moment、返回记录和问问记忆。
- 点击 Moment：朗读该 Moment 的标题与摘要。
- 点击底部操作：返回记录或进入记忆搜索。
- 返回：直接返回上一页。
- 语音唤醒：进入搜索页并立即启动 STT。

### 搜索页

- 上滑/下滑：在语音提问、三个常用问题和返回之间移动焦点。
- 点击：激活当前焦点；监听中再次点击表示完成提问。
- 返回：监听中取消提问；非搜索中返回上一页；搜索执行中拦截返回并提示等待。
- 语音唤醒：直接开始记忆提问。

## 3. STT 状态机

记录页和搜索页使用相同的监听原则：

1. `idle / ready / saved / answered`：不持有 `SpeechRecognition`。
2. 进入 `listening`：设置 `listeningRequested = true`，创建并启动当前页面拥有的 `SpeechRecognition`。
3. 页面 `onHide`：调用 `abort()` 暂停当前识别对象，但保留 `listeningRequested` 和业务阶段。
4. 页面 `onShow`：如果业务阶段仍是 `listening`，重新创建识别对象并恢复监听。
5. 识别自然结束且没有文本：只要页面仍可见、业务仍需要监听且没有识别错误，就重新启动识别。
6. 收到识别文本并结束：记录页进入 Moment 整理，搜索页执行记忆检索。
7. 点击键完成：调用 `stop()` 请求宿主完成当前输入；没有可用识别对象时仍执行基础降级流程。
8. 返回键取消或页面卸载：清除监听请求并调用 `abort()`，旧识别对象的迟到事件通过递增 token 忽略。
9. STT 不可用：页面保留当前业务状态并显示降级提示，用户仍可用四键保存基础 Moment 或选择预置查询。

## 4. Craft 中模拟 STT

Craft 的语音调试流程与真机业务状态保持一致：

1. 点击“触发语音唤醒”；
2. Craft 向页面发送语音唤醒事件；
3. 页面根据当前状态调用 `SpeechRecognition.start()`；
4. Craft 的文本输入框进入可输入状态；
5. 输入模拟转写并提交；
6. 页面收到 `result` 与 `end`，进入保存或搜索流程。

因此，调试输入框是否可用可以作为页面是否真正持有 STT 会话的直观检查信号。

## 5. 回归清单

- 记录页仅用下滑和点击进入时间线。
- 记录页点击后，STT 状态显示“监听中”，模拟输入可生成 Moment。
- 记录监听中按返回，不保存 Moment，并恢复“待命”。
- 时间线可用上下键浏览 Moment，点击可朗读。
- 时间线可用上下键选中“问问记忆”并点击进入搜索。
- 搜索页点击启动 STT，模拟输入后只依据本地 Moment 回答。
- 搜索监听中按返回，取消监听但不离开页面。
- 页面隐藏后当前识别对象被释放；页面恢复后仍处于监听业务状态时重新启动 STT。
